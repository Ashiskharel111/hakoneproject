# SK Limo - Luxury Executive Private Chauffeur & Tour Charters Japan

Official website for **SK Limo** (株式会社SKリモ), offering luxury private chauffeur charters across Tokyo, Mount Fuji, Hakone, Kamakura, Nikko, Yokohama, Karuizawa, and winter ski destinations (Hakuba, Nozawa, Shiga Kogen).

---

## 🌟 Key Features

- **Full 5-Language Localization**: English (`en`), Japanese (`ja`), Chinese (`zh`), French (`fr`), and Spanish (`es`) with persistent language selection.
- **Executive Fleet Showcase**: Toyota Alphard Executive Lounge, Toyota Granace Premium Lounge, and Toyota HiAce Grand Cabin with exterior, interior, and luggage trunk gallery tabs.
- **Dedicated Portals**:
  - `/tours`: Executive Day Tours & Grand Packages landing
  - `/tours/winter`: Winter Alpine Ski Charters & 4WD transfers
  - `/tours/airport-transfer`: Haneda (HND) & Narita (NRT) door-to-door transfers
  - `/destinations`: Sightseeing hub with dynamic category filter
  - `/destinations/[id]`: In-depth destination guides and itineraries
- **Compliance & Credibility**: Official MLIT License (緑ナンバー 一般乗用旅客自動車運送事業) and Kashiwa Reysol Official Partner branding.
- **Responsive & Mobile-First**: 100% full-screen mobile menu, optimized vehicle framing, and sticky category bar.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000/tours](http://localhost:3000/tours) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Start Production Server
```bash
npm run start
```
